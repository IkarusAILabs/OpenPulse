# Reproducing the results

Everything in `research/results/`, `research/tables/` and `research/figures/` is generated by one command, offline. CI regenerates it on Ubuntu and Windows and fails on any byte of difference (`.github/workflows/ci.yml`, job `research`).

## 1. Environment

- **Python:** 3.10 or later. The committed outputs were produced, and `--check` verified, with 3.14.6 on Windows. The CI job re-checks them with 3.11 on Ubuntu and Windows; that has not yet run at the time of writing.
- **Network:** none. **Accounts or private infrastructure:** none.
- **Not needed:** Node, Go and Java (the baseline V comparators; §4) and TeX (paper only).

```bash
python -m venv .venv
```

Activate it (`. .venv/bin/activate`, or `.venv\Scripts\activate` on Windows). Then install the hash-pinned runtime and MCP locks; the MCP lock supplies `jsonschema` for dataset schema validation:

```bash
python -m pip install --require-hashes -r requirements.lock -r requirements-mcp.lock
```

```bash
python -m pip install --no-deps -e .
```

The research scripts use only the standard library and the packages already pinned. They add no runtime dependency.

## 2. Commands

| Step | Command | Expected output |
|---|---|---|
| Validate the case sets | `python research/scripts/validate_dataset.py` | `valid ... 27 events, 167 cases, 0 independently labelled, sha256 70832760ff41` and the dev equivalent; exit 0 |
| Reference oracle and invariants | `python conformance/matrix.py`; `python conformance/randomized.py --cases 100000 --seed 7`; `python conformance/invariants.py` | 6,195 cases (6,123 conform, 72 label-only); 100,000 conform; 12,000 cases, 0 violations |
| Defect re-injection (about 3 min) | `python conformance/mutation.py` | `caught 23 of 23 mutants` |
| Baselines and OpenPulse on the same cases | `python research/scripts/evaluate.py retro` (and `dev`) | per-policy category counts |
| Metrics and intervals | `python research/scripts/inference.py retro` | k/n with intervals |
| Cross-version comparison | `python research/scripts/compare.py retro` | `after fixes (abcb685) -> current: 0/167 pairs changed` |
| Tables and figures | `python research/scripts/tables.py` | `research/tables/*.md`, `*.tex`; `research/figures/*.svg` |
| **Everything, plus the manifest** | `python research/scripts/reproduce.py` | `wrote 34 outputs and results/MANIFEST.json` |
| **Validate the package** | `python research/scripts/reproduce.py --check` | `reproduced: 34 outputs identical; source <hash>` |
| Tests | `python -m pytest -q` | the whole suite, including `test_decision_invariants`, `test_research_pipeline` and `test_research_surfaces` |

`reproduce.py --full` also re-runs the 100,000-case randomised differential and requires exact agreement with `conformance/results/randomized.json`.

## 3. What `reproduce.py` does, and when it fails

1. Validates both case sets against `research/dataset/schema.json`, their recorded SHA-256 and the label vocabulary. **It fails** on a missing field, an invalid label, an unknown event, a duplicate id or a hash mismatch.
2. Re-runs the oracle matrix, the randomised differential (5,000 cases, seed 2026; with `--full`, 100,000, seed 7) and the decision invariants. **It fails** if a count differs from `conformance/results/` or if any invariant is violated.
3. Runs every registered and post-hoc policy (`evaluate.py`). **It fails** if a baseline raises an error.
4. Computes intervals and paired comparisons (`inference.py`), and compares versions (`compare.py`). **It fails** if versions evaluated different case files.
5. Builds tables and figures from the result files only (`tables.py`). **It fails** if an expected result file is missing.
6. Writes `results/MANIFEST.json`, containing:
   - a SHA-256 over every source file that can change a number (line endings normalised);
   - the commit and whether the tracked tree was clean;
   - Python and package versions;
   - dataset hashes and seeds;
   - the hash of every output.

`--check` regenerates into a temporary directory. **It fails** if:
- any output differs from the committed one, or exists on one side only; or
- the committed manifest's source hash differs from the tree being checked, meaning the results were not produced from this code.

## 4. Determinism and its limits

- **Randomness.** All of it is seeded:
  - bootstrap 20261031 (research) and 20261030 (registered);
  - generators 2026, 7, and 11/12/13.
  `random.Random` is stable across Python 3 versions.
- **Clock and network.** None are read. Each event is replayed as of its recorded knowledge cut.
- **Baseline V's comparators.** `--comparators off`, the default, runs V without the npm/Go/Maven bridges on every machine alike, so results do not depend on which toolchains a runner has. The registered configuration is `python research/scripts/evaluate.py retro --comparators required`, after installing the bridges as in `evaluation/comparators/README.md`. The frozen retrospective results were produced that way, and they match the comparator-free run pair for pair (`research/tables/retro_versions.md`).
- **Known sources of nondeterminism:** none.

## 6. Limitations

- Reproducing these numbers reproduces the developer's labels, not an independent judgement (THREATS_TO_VALIDITY.md).
- The manuscript PDF is built in CI, not locally. No TeX toolchain was available when the draft was written.
