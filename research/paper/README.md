## How claims are kept honest

- Every number in the prose is a macro from `numbers.tex`. `reproduce.py --check` fails if the macro file no longer matches the results.
- Each section says what kind of evidence it rests on:
  - design (§4);
  - implementation and tests (§5);
  - retrospective observation on developer labels (§7);
  - untested hypotheses and future work (§10).
- `\draftnote{}` marks decisions and checks that remain. Remove each one only when it is resolved.
